# Data and startup

Read the `Configuration and application data` section of
`docs/configuration.md` when a task concerns:

- `OPENAGENT_HOME`, development roots, platform migration, or durable files;
- configuration/database compatibility, backups, reset, or consent;
- runtime single-writer ownership and startup ordering;
- embedding, runtime, frontend, plugin, channel, or log resource locations.

The authoritative details remain in the linked public document. Use its exact
paths, version boundaries, backup guarantees, and interactive versus
standalone startup behavior; do not infer compatibility paths.
