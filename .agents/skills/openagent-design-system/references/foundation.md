# Design foundation

Use `docs/design.md` sections `Colors`, `Typography`, `Layout`, `Elevation &
Depth`, and `Shapes` for changes to tokens or visual primitives. Read only
those sections, not the component catalog, unless the task crosses both.

Use the exact token names and semantic surfaces from the public document.
Avoid introducing a second accent system, unbounded decorative depth, or
component-local values that bypass shared theme tokens.
