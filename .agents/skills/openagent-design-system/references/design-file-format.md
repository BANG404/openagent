# DESIGN.md format

Read `docs/designmdrefer.md` only when creating or parsing a `DESIGN.md` file.
Route by heading: `Schema` and `Section Order` for structure, `Design Tokens`
for token declarations, and `Consumer Behavior for Unknown Content` for
forward-compatible readers.

Do not copy the full format reference into a skill body; the public reference
is the single source of truth.
