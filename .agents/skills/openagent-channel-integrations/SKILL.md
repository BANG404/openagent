# Channels and remote gateway

Use the shared SDK Runtime. Keep platform adapters, peer/workspace scope and transport authorization with their respective owners.

- For messaging platforms, pairing, routing and channel settings, read [messaging channels](references/messaging-channels.md).
- For remote web access, authentication, LAN policy and the browser transport, read [remote gateway](references/remote-gateway.md).

Frontend presentation changes also follow the relevant chat or design contract. Private transport implementation follows `runtime/AGENTS.md`.
