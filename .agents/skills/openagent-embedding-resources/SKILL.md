# Embedding resources

Read [model-provenance.md](references/model-provenance.md) for the model source,
pinned revision, byte size, checksum, and reproducibility procedure. For staged
installation, activation, repair, and startup UX, read
[data-and-startup.md](../openagent-configuration/references/data-and-startup.md)
and [save-and-reload.md](../openagent-configuration/references/save-and-reload.md).

Resources are immutable and must be staged and fully verified before activation.
