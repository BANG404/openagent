## 选择起点

| 想扩展什么 | Plugin Kit 模板 |
| --- | --- |
| 可复用指令 | `minimal` 或 `skill-pack` |
| MCP 服务提供的工具 | `mcp-tools` |
| 斜杠命令 | `slash-commands` |
| 带作用域的侧栏 | `sidebar-panel` |
| 生命周期钩子 | `automation-hooks` |
| 工具租约或受监管的进程 | `mcp-lifecycle` 或 `daemon` |

## 参考当前的独立插件

[插件开发助手](https://github.com/BANG404/openagent-plugin-kit) 既是公开工具链，也是可安装的开发助手。[Chat Groups](https://github.com/BANG404/openagent-chat-groups)、[Goal](https://github.com/BANG404/openagent-goal)、[Graph](https://github.com/BANG404/openagent-graph)、[Cua Driver](https://github.com/BANG404/openagent-cua-driver) 和 [Message Board](https://github.com/BANG404/message-board) 分别独立安装。Multi-Agent V2 属于 Runtime 能力；Goal 和 Graph 通过共享 Host Bridge 实现插件自己的工作流。

本教程依据当前公开 Plugin Kit 的模板与校验器编写。旧版 Runtime 即使接受插件协议 1，也可能缺少可选的桥接操作，调用前应检测支持情况。逐字段规范以 [Plugin Kit 文档](https://github.com/BANG404/openagent-plugin-kit/tree/main/docs) 为准。
