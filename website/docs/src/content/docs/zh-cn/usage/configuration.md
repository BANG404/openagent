## 配置并测试模型服务

打开**运行 → 模型 → 模型服务**。添加或选择服务，设置服务类型，填写请求地址与所需凭据。先点击**检测**，再获取模型列表，或添加账号支持的精确模型／部署名称，并保持服务启用。

然后打开**模型 → 默认模型**，分别选择对话与 Flash 的服务和模型。切换服务也会改变可选模型，编辑服务后检查两项绑定。发送一条简短对话；修改 Flash 后，也检查相关后台任务。

| 设置 | 如何填写 |
| --- | --- |
| 请求／API 地址 | 使用服务商的 API 端点，不是官网或登录页面 |
| 接口模式 | 按服务支持选择 Responses 或 Chat Completions 等适用接口 |
| 模型名称 | 使用精确的 API 模型或部署标识，不只填写展示名称 |
| 视觉能力 | 仅为真正支持图片输入的模型和接口开启 |
| 推理强度 | 仅在服务接受对应参数时开启 |
| 上下文窗口 | 填写模型真实上限，也会限制自动压缩阈值 |

ChatGPT OAuth 使用内置模型列表，可能落后于账号实际可用模型，需要时手动添加。再次获取该列表会替换已配置列表，包括手动条目。成功获取列表或检测服务后，仍须实际调用模型验证。

需要时在默认模型中配置备用模型、重试次数与间隔，备用模型也须对账号可用。认证失败、模型名称错误或参数不受支持时，应修正设置，反复重试不能解决原因。

## 区分审批与执行权限

输入框的审批选择器只快捷切换审批模式。**运行 → 执行与权限**还提供独立的文件系统与网络策略：

| 审批模式 | 行为 |
| --- | --- |
| 手动 | 除明确豁免的生命周期控制外，工具调用等待审阅 |
| 自动 | Flash 评估工具调用，有明显影响或判断不确定时转人工审批 |
| 关闭 | 不走审批流程，执行权限策略仍然有效 |

审批默认关闭，但它**不会**选择或关闭沙盒。允许某个命令，不能使被禁止的路径或网络连接自动可用。

托管执行提供工作区可写、只读和高级路径规则，网络访问单独配置。默认允许宿主范围读取、活动工作区内写入；宽泛的可写规则仍将 `.git`、`.agents`、`.codex` 保持只读，更具体的显式规则可以改变边界。任务需要其他位置时，检查实际配置。关闭隔离则使用应用进程自身的访问能力。

平台辅助程序不能落实所选策略时，托管命令会失败。Windows 首次使用受限网络时，可能需要通过正常沙盒准备流程确认 UAC。应通过普通 Agent 命令修复具体准备错误；安装插件不会为它授权或完成沙盒配置。

## 安装并使用插件

1. 打开**集成 → 插件**，浏览或搜索商店，先核对用途、语言、平台前提与 README。
2. 点击**安装**并等待任务完成。请求真实电脑访问的包会单独弹出授权；选择**暂不授权**会保留安装，但不授予该访问。
3. 在“已安装”中确认启用状态，填写必要配置，并按需授权外部服务。
4. 使用包说明的命令，或让 Agent 执行一项具体支持的操作，检查实际工具结果和可用面板。

插件启用、Direct/Relay 工具挂载、真实电脑访问和供应商授权是分别控制的。**跟随插件声明**会移除用户挂载覆盖；Direct 让工具直接可用，Relay 让 Agent 通过 `load_tool` 发现和挂载。角色可用性与当前权限策略仍然有效。

插件更新独立于桌面版本。检查更新后，可使用**更新**或**全部更新**；活动工作可能延迟激活。本地目录作者可以[刷新已关联源码](../../plugins/local-development/)。卸载会保留包数据和私有设置。

连接自己的 MCP 服务时，使用**集成 → 扩展**配置支持的 stdio 或 HTTP 传输，检查可执行程序与依赖，或端点与认证。插件自带 MCP 应由插件管理，不要再复制成用户服务。

## 保存可复用指令与偏好

| 内容 | 范围与用途 |
| --- | --- |
| 全局用户记忆 | 当前应用数据目录的 `memory.md`，保存长期个人偏好 |
| 工作区记忆 | `<workspace>/.agents/memory.md`，保存项目上下文 |
| 全局 Skill | `~/.agents/skills/<name>/SKILL.md` |
| 工作区 Skill | `<workspace>/.agents/skills/<name>/SKILL.md` |
| 角色 | 可为对话或委派选择的可复用 Agent 工作流 |

Skill 需要 YAML `name` 和 `description`，按任务相关性加载。使用记忆界面或 Agent 记忆工具维护内容，不要为排错直接覆盖已有笔记。外观和语言跟随常规设置；主题插件修改声明的外观 token，不改变模型行为。

对话数据保存在本地，但模型请求会把选中的提示、上下文和附件发给所配置服务。插件和 MCP 也可能访问自己的服务商。可在**常规设置 → 隐私与诊断**修改自动诊断偏好，主动上报问题是另一项操作。备份与求助方法见[常见问题](../troubleshooting/)。
