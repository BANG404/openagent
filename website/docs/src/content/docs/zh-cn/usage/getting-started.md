---
title: 安装与首次使用
description: 安装 OpenAgent，连接模型服务，选择工作区，并完成第一次有用的对话。
---

OpenAgent 是一个桌面工作区，Agent 可以读取项目文件、编辑内容、运行工具并保留对话历史。建议先完成一个只读小任务，再让它修改项目。

## 1. 选择桌面安装包

从 [OpenAgent Releases](https://github.com/BANG404/openagent/releases) 或[官网的下载选项](../../../../#download)选择匹配操作系统和架构的包。需要选择包含桌面安装程序的版本；只有组件的 Release 用于更新现有安装。

| 包类型 | 首次启动行为 |
| --- | --- |
| 完整包／离线包 | 包含 Runtime、界面、本地 embedding 资源与平台辅助程序，Windows 还包含 WebView2 |
| 在线包 | 首次设置时下载并核验应用资源 |

离线包可以免去应用资源下载，但选择的模型服务仍可能需要联网。OpenAgent 不附带云端模型订阅或 API 凭据。

## 2. 完成首次设置

打开应用，按设置窗口操作：

1. 等待必要资源就绪。准备失败时，使用界面的重试或离线导入，并查看具体资源错误。
2. 在偏好设置中选择语言、主题和已存在的**工作区文件夹**。工作区就是希望 Agent 工作的项目目录。
3. 添加模型服务，选择真实的服务类型，填写端点与凭据，或完成受支持的登录，然后检测连接。
4. 获取或添加账号可用的模型，选择**对话模型**与 **Flash 模型**，检查摘要后完成设置。

对话模型负责主要交互。Flash 负责标题、上下文压缩等小型后台任务，也用于已配置的自动审批检查。模型列表中存在某个名称，不代表账号一定能调用它；还要发送一条简短消息验证。以后可在**运行 → 模型 → 默认模型**中修改这两项。

OpenAI 兼容服务的地址可以是域名、`/v1` 根路径或完整 `/chat/completions` 地址，应用会规范化为 API 根路径。接口模式须与实际服务一致，详见[模型与权限](../configuration/)。

## 3. 完成第一个任务

在所选项目中新建对话，发送：

```text
阅读项目 README 和主要源码目录，说明项目用途，并列出三项值得继续做的任务。附上实际阅读的文件引用，暂时不要修改文件。
```

通过工具卡片确认它读取了哪些文件。出现结构化问题或审批请求时，回答当前等待的表单或工具请求。检查文件引用后，再提交具体修改需求。

第一次修改可以同时说明目标与验证方法：

```text
完善这个项目 README 中的安装步骤。先核对现有脚本，确保命令可以执行，完成后展示变更差异和实际运行的检查。
```

检查文件变更面板和工具结果，再继续阅读[对话、文件与恢复](../conversations/)。

## 4. 找到常用入口

| 想做什么 | 从哪里开始 |
| --- | --- |
| 打开项目或另开窗口 | 文件菜单 |
| 修改服务、模型与默认绑定 | 运行 → 模型 |
| 设置审批和执行边界 | 运行 → 执行与权限 |
| 配置后台任务 | 运行 → Flash 任务 |
| 安装插件或连接 MCP | 集成 → 插件／扩展 |
| 修改语言、主题或诊断偏好 | 编辑 → 设置 → 常规设置 |
| 反馈可复现的问题 | 帮助 → 上报问题 |

无法发送或不能完成设置时，使用[常见问题与排查](../troubleshooting/)。诊断设置失败时保留工作区与已有应用数据；删除历史记录不能修复模型连接。
