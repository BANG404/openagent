## 提出清晰的任务

先打开目标工作区，再开始项目对话。说明预期结果、相关文件、约束和可观察的成功标准，例如：

```text
修复这个项目的搜索清空行为。先阅读搜索组件与测试，沿用现有界面风格，验证清空查询后恢复完整列表。完成后列出修改的文件与验证结果。
```

工作区让项目工具有明确目标，不会自动把所有项目文件都发送给模型。让 Agent 阅读相关文件，并检查实际工具结果。反复使用的要求适合放进项目指令或 Skill，无须每轮粘贴整个仓库。

Enter 发送消息或选中已打开的建议，Shift+Enter 换行。Agent 运行时，根据消息应当等待还是引导当前工作，使用界面提供的排队或引导控件。停止会取消活动执行；看似很久没有进展的任务，也可能正在等待问题回答或审批。

## 附加与复用上下文

使用附件入口、拖入文件或粘贴支持的内容。发送前检查待发送卡片，移除不需要的附件。图片输入要求为**当前所选模型**启用视觉能力；PDF 和文档处理取决于模型及其 API 支持。能够上传不代表模型一定能读取，桌面预览也不会内嵌 PDF。

输入框最多支持八个附件，每个 20 MB。支持附件上传时，超过 1,000 个 Unicode 字符的粘贴文本会变为文本附件。文件标签关联对应附件，删除标签或预览都会移除该附件，并重新编号剩余引用。

选中助手回复的一部分，使用**添加到对话**将其作为引用加入下次请求。在草稿旁检查待发送引用，这会保留来源关系，同时不改写你正在编辑的消息。

## 判断执行状态

| 界面状态 | 应如何操作 |
| --- | --- |
| 正在输出或工具运行中 | 观察进度，按需展开相关工具卡片 |
| 审批请求 | 检查实际操作及参数，再允许或拒绝 |
| 结构化问题 | 使用对应表单提交回答 |
| 工具或模型请求失败 | 读取错误，修复原因后再重试 |
| 等待重试 | 检查配置的模型重试队列；不再继续时点击停止 |

允许的调用仍可能因权限或服务校验失败。工具卡片中的待执行变更不代表已经成功，须查看结果。右侧详情面板会按实际可用内容展示插件工作流、文件变更和终端。

## 审阅修改与探索替代方案

接收结果前检查文件内容与差异。编辑历史用户消息或从该处重新生成，可以探索另一条续接路径。留意当前选中的会话分支，不同分支可能有不同消息、活动任务和插件视图。

使用应用的检查点或文件恢复动作前，先核对其说明的范围。对话回滚与文件回滚是不同效果，也不会撤回工具已经发送的邮件、已修改的远程服务状态等外部操作。大幅修改前保留项目 Git 提交或备份仍然有用。

停止任务只阻止后续执行，不会自动撤销已完成的文件写入。失败或取消后，先检查变更面板，再用具体修正要求继续。

## 长对话与可复用知识

自动上下文压缩会为长对话总结模型上下文，同时保留可见历史。可在**运行 → Flash 任务**中配置，并在模型配置中填写真实上下文窗口；设置窗口后，触发阈值最高为该窗口的 90%。压缩不等于删除历史，也不能替代明确的任务要求。

使用记忆界面保存长期偏好和可复用知识，注意全局与工作区范围不同。自动 Agent 记忆检索默认关闭，需要时在 Flash 任务中配置。上下文压缩、已保存记忆和 Skill 指令承担不同用途。

需要定时续接时，让 Agent 安排并展示待执行 hook，也可以让它列出或取消计划。Goal、Graph、Chat Groups 提供独立安装的工作流，按包的实际用途选择即可。继续阅读[模型、权限与扩展](../configuration/)和[常见问题](../troubleshooting/)。
