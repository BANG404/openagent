One workspace, the complete loop

More than a chat window.

OpenAgent combines an agent runtime, project tools, durable context, and desktop controls so useful work can continue across turns and sessions.

01

Agent runtime

Stream conversations, delegate sub-agents with Multi-Agent V2, and ask structured follow-up questions. Add Goal or Graph plugins for persistent workflows.

02

Tools & MCP

Apply patches, inspect images, run terminal commands, and connect external MCP servers over HTTP or stdio.

03

Memory & skills

Recall useful knowledge across sessions with hybrid search, and load reusable global or workspace-scoped SKILL.md instructions.

04

Desktop automation

Install the Cua Driver plugin for desktop automation, with host supervision and per-tool controls.

05

Messaging channels

Continue durable, scoped Agent conversations from Feishu/Lark, Telegram, QQ, WeChat, Discord, or Slack.

06

Checkpoints & branches

Search conversations, keep a durable checkpoint for every turn, branch from earlier messages, inspect diffs, and roll work back.

07

Rich, interactive output

Render streaming Markdown, code, Mermaid, ECharts, file and URL chips, plus image and video media.

08

Models & context

Connect Anthropic, OpenAI, or compatible providers, switch models, attach multimodal files, and compact long conversations.

09

Scheduled continuations

Ask the Agent to schedule a timed or completion-triggered continuation, then inspect or cancel pending hooks through its tools.

10

Workspace knowledge

Keep memory and skills scoped to a project or shared globally, with workspace DESIGN.md guidance.

11

Desktop experience

Reuse the existing primary window on repeated launches, keep workspaces in dedicated windows, and use native tray and file-manager controls.

12

Modular updates

Update the frontend, Runtime, and desktop shell independently, with separate plugin updates from verified GitHub releases.

Autonomy,
with receipts.

Choose how independently agents can act while preserving the evidence needed to understand, approve, or undo their work.

01

Flexible approvals

Review every call, use model-assisted approval, disable approval, or apply the workspace sandbox.

02

Workspace boundaries

File and terminal actions stay aligned with the active project and its configured access policy.

03

Durable recovery

Conversation snapshots, branches, cancellations, and reverse diffs make experimentation recoverable.

04

Optional observability

Inspect local run details and optionally connect Langfuse tracing when deeper diagnostics are useful.
